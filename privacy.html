应用说明隐私政策

隐私政策

适用于“投资日结单”个人应用。更新日期：2026 年 9 月 29 日。

数据使用

汇总邮箱内信息，形成投资总结。不会发送、删除邮件或修改已读状态。数据不出售，不用于广告或模型训练。

处理与保存

通过 Google 读取邮箱，在 GitHub 云端处理，不向其他服务传送数据。

授权与联系

可随时在 Google 账号连接管理 撤销权限，并删除 GitHub 中的凭据和日志。政策问题可通过 维护者的 Issue 页面 联系，请勿提交隐私信息。

本应用对 Google API 数据的使用及传输遵守 Google API 服务用户数据政策，包括“有限使用”（Limited Use）要求。数据处理方式改变时，将更新本政策并取得必要授权。
